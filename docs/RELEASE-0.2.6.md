# 0.2.6 — Lista visível de uso das tags

A análise agora mostra todas as tags individuais observadas na métrica e no intervalo selecionados, antes da comparação global. O filtro inicial lista as tags sem referência encontrada. Cada linha mostra se a ausência de uso foi verificada ou se continua pendente, a redução simulada de combinações e uma ação para simular aquela tag.

Filtros permitem ver tags sem uso observado com cobertura completa e atual, tags pendentes, tags com dependências ou todas as tags. A busca encontra uma tag pelo nome. Referências mostram consultas, monitores e dashboards relacionados.

Histórico e cobertura incompleta não confirmam ausência de uso. A lista reutiliza a análise carregada e não dispara consultas externas adicionais. A simulação não habilita pipelines nem representa redução real de ingestão.
