# 0.2.7 — Seleção acumulada de tags

As ações da lista adicionam ou removem tags da seleção compartilhada. Adicionar uma segunda tag preserva a primeira. Busca e filtros não removem seleções. Tags selecionadas aparecem acima da tabela com ações para desmarcar e limpar o conjunto.

O resultado conjunto aparece junto à lista e recalcula as combinações para todas as tags selecionadas, preservando host e demais dimensões. Percentuais individuais não são somados. Os painéis de simulação, dependências e revisão usam a mesma seleção.

O ranking de cenários continua permitindo escolher um cenário completo. Nenhuma transformação de produção é habilitada.
